# docs/testing/

โฟลเดอร์นี้เก็บเอกสารที่เกี่ยวกับการทดสอบระบบ สร้างในช่วงที่ 3: Testing & Deployment

## ไฟล์ที่จะสร้างในช่วงที่ 3

| ไฟล์ | วัตถุประสงค์ |
|------|------------|
| `TESTING_PLAN.md` | แผนการทดสอบระบบ (strategy, scope, tools) |
| `UAT_PLAN.md` | User Acceptance Testing plan |
| `backend-test-cases.md` | API test cases พร้อม curl/Postman steps |
| `frontend-test-cases.md` | UI test cases พร้อม interaction steps |
| `phase-N-test-results.md` | ผลการทดสอบแต่ละ Phase |
